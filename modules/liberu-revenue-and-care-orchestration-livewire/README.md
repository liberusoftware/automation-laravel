# Liberu RevenueAndCareOrchestration livewire

This package is the one-to-one **livewire** presentation adapter for `liberusoftware/liberu-revenue-and-care-orchestration`.

It owns only livewire transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/liberu-revenue-and-care-orchestration-livewire`
- Installer name: `liberu-revenue-and-care-orchestration-livewire`
- Package type: `liberu-module`
