# Liberu RevenueAndCareOrchestration filament

This package is the one-to-one **filament** presentation adapter for `liberusoftware/liberu-revenue-and-care-orchestration`.

It owns only filament transport/presentation integration. Domain rules, persistence, authorization, tenancy, and lifecycle behavior remain in the matching core package.

- Composer package: `liberusoftware/liberu-revenue-and-care-orchestration-filament`
- Installer name: `liberu-revenue-and-care-orchestration-filament`
- Package type: `liberu-module`
